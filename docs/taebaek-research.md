조사일 2026-11-19. 웹 사진은 저작권 때문에 가져오지 않았고, 조사 내용을 바탕으로 원작 아틀라스 화풍(종이·펠트 컷아웃, 크림색 칼선 테두리)에 맞춘 일러스트를 새로 생성했습니다(sprite-gen, 지피티/codex, 원작 아틀라스 콜라주를 화풍 참조로 사용).

## 3. 생성된 에셋 (`art-src/taebaek/raw/`, 프롬프트는 `art-src/taebaek/prompts/`)
- 단일 일러스트 10장: `school_front`, `daiso_front`, `claw_front`, `library_front`, `kkachibal_front`, `coal_plant`, `mine_entrance`, `gumunso`, `cheonjedan`, `geomnyongso`
- 2×2 시트 7장(28종):
  - `sheet_trees_a`: 주목, 주목 고사목 상고대, 분비나무, 사스래나무
  - `sheet_trees_b`: 신갈나무(가을), 함박꽃나무, 향나무, 개나리
  - `sheet_flowers`: 금대봉 야생화 군락, 노랑무늬붓꽃, 고랭지 배추밭, 해바라기
  - `sheet_hub_props`: 철쭉, 인형뽑기 기계, 산소 방울 모빌, 황지 며느리상
  - `sheet_coal_props`: 탄차, 연탄 더미, 풍력발전기 기둥, 풍력발전기 날개(회전용 분리)
  - `sheet_animals`: 어치, 산양, 열목어, 삼엽충 화석
  - `sheet_misc`: 삼수령 조형물, 빈 표지석, 미끄럼틀, 교문 기둥

## 4. 진행 상황
- 완료(1차, 2026-11-19): 원본 클론·의존성 설치·실행 확인, WFC 솔버 옵션 한도 96→128 확장(시드 7 결과가 기존과 동일함을 확인), 조사, 일러스트 17장 생성.
- 완료(2차, 2026-11-19):
  - 아틀라스 합성: `art-src/taebaek/slice_items.py`(시트 슬라이스) → `compose_atlas.py`(한글 간판 인쇄, 색 번짐 처리, 다이컷 윤곽선, y≥2600 빈 영역 배치). 원본 아틀라스는 `art-src/taebaek/base/`에 보관하고 매번 거기서 다시 합성.
  - 카드 키트 `src/world/kit.js`: tiles.glb에 없는 19개 타일을 실행 중에 조립(기증 타일의 바닥 인쇄 + 아틀라스 윤곽선으로 자른 카드, 경첩 `userData` 규격 동일). 상점 정면은 안쪽으로 접히는 옆벽 포함, 풍력발전기 날개는 회전.
  - 황지 생활권: 시작 도로 주변에 6칸 고정 배치(`src/world/wfc.js` ORIGIN_FIXED) — 서쪽 학교·운동장·도서관, 동쪽 황지연못·다이소·인형뽑기.
  - 바이옴: 철암(갱도·선탄장·까치발·구문소), 매봉산(풍력발전기·배추밭·해바라기·삼수령, 초록 고원 색보정, 사막 전용 타일 퇴출), 태백산(천제단·주목 군락), 금대봉(검룡소·야생화·철쭉).
  - 학급 마스코트 NPC 11명: 종이 펠트 화풍으로 다시 그림(`art-src/taebaek/npc/`, `compose_npcs.py` → animals 시트 2048×2560), 각자 집 타일 근처를 돌아다니고 가까이 가면 말풍선(`src/game/npcs.js`).
  - 태백 도감 19곳: 처음 밟으면 한 줄 이야기 알림, 시드별 localStorage 저장. 한글 안내문·지도 라벨.
- 남은 일: 상점·도서관 창문 야간 발광(유리 패널 위치 검출), 가로등 퀘스트를 하굣길 순서(학교→연못→다이소→도서관)로 묶기, 도감을 지도(Tab)에 표시, 학생 그림 카드 슬롯, 4개 시점 스크린샷 비평 루프.
